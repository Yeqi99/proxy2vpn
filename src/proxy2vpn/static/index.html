02 / CONNECT

连接教程

保存配置后，按下面一种方式接入。端口和账号以当前设置为准。

路由器 · L2TP

  1. 在浏览器打开路由器管理页并登录。
  2. 找到「VPN 客户端」，添加 L2TP（不带 IPsec）。
  3. 填入本机内网 IP、下面的账号与密码，然后连接。
  4. 按设备分流，只加入目标设备。不要加入运行代理的这台电脑，避免循环。

路由器 · WireGuard

  1. 先启用 WireGuard 并保存。
  2. 下载下方客户端配置，在路由器的 WireGuard 客户端中导入。
  3. 按设备分流，并排除本机。文件含私钥，请妥善保管。

浏览器 · HTTP

  1. 先启用 HTTP 并保存。
  2. Chrome / Edge：打开系统代理设置，手动填写本机内网 IP 和 HTTP 端口。
  3. Firefox：设置 → 网络设置 → 手动代理，填写 HTTP 地址和端口，并用于 HTTPS。
  4. 出现认证窗口时，输入下面生成的账号密码。SOCKS5 入口请使用支持用户名密码认证的应用；浏览器优先使用 HTTP。
账号密码只在点击后显示。

如果连不上：检查原代理已启动、IP 是否变化、防火墙是否放行对应端口，以及 Wi-Fi 是否开启了访客或客户端隔离。WireGuard 当前提供一份客户端配置；不同路由器不要同时复用。
